2. How to Use

Voice: click “Start Voice Control” or press the space bar and then speak a command. One spoken phrase can contain several commands at once, chained with “and” or by repeating “set,” for example “set minimum magnitude to 5 and maximum magnitude to 7.” After the first click, listening restarts automatically after every command, so only one click is ever needed per session. Click the button again or press space again to stop.

Recognized commands: set minimum magnitude to 5, set maximum magnitude to 7, set minimum depth to 10, set maximum depth to 100, select type as earthquake (or landslide, or all), select status as reviewed (or automatic, or all), start camera, stop camera, run, or reset (reset also clears the feedback panel back to its starting state).

Gesture: click “Start Camera” or say “start camera,” then show one hand to the camera. An open palm runs the current filters, a closed fist resets every filter, a thumb-down scrolls the table down, and a thumb-up scrolls the table back up. A short cooldown after each detected gesture stops one held pose from repeating the same action many times a second.

Fallback: every filter, the run button, and the table header sorting all still work with a normal mouse click or keyboard entry with or without voice or camera access.

3. Design Reflection

This lab extends the Lab 3 earthquake table and its six filters with two novel interaction modalities. Voice commands, using the browser Web Speech API, can set the numeric filters, choose the type or status dropdown, start or stop the camera, apply the filters by saying run, or clear everything by saying reset. A single utterance can carry several chained commands and listening restarts automatically after each command, so only one click or key press is needed per session.

Hand gestures, using the MediaPipe Gesture Recognizer on the webcam feed, map an open palm to running the filters, a closed fist to resetting them and a thumb down or thumb up to scrolling the table down or up. Both modalities support the same task the mouse controls already support: narrowing 1,500 earthquake records down to a relevant subset by magnitude, depth, type and status, then reading through the results. Voice suits this task because stating several filter values in one sentence is faster than clicking into each field in turn, and gesture suits it because open palm, closed fist, and a thumb pointing up or down are easy, visually distinct poses that work well as one-shot commands without needing a free hand on the mouse. Voice recognition handled clear phrases well but occasionally missed a command or misheard a number in a noisy room. Gesture recognition needed decent lighting and a hand held close to the camera, and a relaxed hand was sometimes read as a weak closed fist, which the cooldown timer helped with.
