1. Dataset Description

The dataset contains 27 countries across 6 continents and 14 areas drawn from data/lab6_assignment_gdp.csv. Each row lists a continent, an area within that continent, a country, the country's GDP in US dollars and a GDP status of increase, unchanged or decrease. GDP ranges from 120 billion dollars for Kenya to 27,800 billion dollars for the United States. Fifteen countries have a status of increase, seven have a status of unchanged and five have a status of decrease. Because this range is wide, rectangle area in both treemaps is proportional to the square root of GDP rather than GDP itself. This keeps the smallest countries visible without changing which countries appear larger or smaller. Tooltips always report the true GDP value, not the transformed one.

The flat CSV was converted into nested JSON with a Python script (convert_hierarchy.py), which groups the rows by continent, then by area, then by country. The result is saved as data/lab6_gdp_hierarchy.json and loaded directly by both treemaps below. The hierarchy used in both treemaps is world, then continent, then area and then country.

2. GDP Hierarchy Treemap: Squarify Tiling

Each treemap shows the same hierarchy and the same data. Rectangle area encodes GDP in US dollars and rectangle color encodes GDP status. Outlined boxes group countries by area, and larger outlined boxes group areas by continent. Hover over a country rectangle to see its continent, area, GDP and status.

This treemap uses the same hierarchy, the same values and the same color encoding as Figure 1, but only the tiling method changes. The Binary method recursively splits the available space into two groups at each step which produces a different set of rectangle shapes than Squarify.

4. Design Description

GDP amount is encoded through rectangle area because area is the strongest channel for comparing many quantities at once, and it is the default channel a treemap provides. Area is scaled to the square root of GDP, not GDP itself. This keeps the smallest countries visible instead of shrinking to invisible slivers, and the size order stays the same. GDP status is encoded through color because status has only three categories and color works well for small categorical sets. Green marks increase, gray marks unchanged and red marks decrease, which matches common expectations for growth and decline. Outlined boxes around each area and continent make the hierarchy visible without adding extra rectangles that would compete with the country rectangles for attention.

The Squarify treemap keeps most rectangles close to a square shape. This makes countries easier to compare because their proportions stay similar across the layout. The Binary treemap recursively splits space into two groups at each step. This produces longer, thinner rectangles in some areas, making small countries harder to label. It keeps sibling countries grouped in a clear order. Comparing the two layouts shows that segmentation strategy changes readability even though the data and hierarchy stay the same.
